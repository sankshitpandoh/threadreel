The Front Page

Every frame of your video, strung from one thread.

Give Threadreel a clip and it hammers a ring of pegs around each frame, then runs a single thread from peg to peg in straight lines, thousands of times, until the picture appears. Play the frames back and the thread moves.

After the string-art pieces of Petros Vrellis and Jérémie Piellard's image-stylization-threading. Runs entirely in your browser; nothing is uploaded.

II.

The Method

How a frame becomes a few thousand straight lines.

A string artist has only one move: run the thread from the peg they are at to some other peg, in a straight line. Threadreel plays that game greedily. It keeps a small copy of the frame in which every pixel records how much darker it still needs to be. From the current peg it considers every other peg, averages the remaining darkness along each possible line, and goes to the peg whose line crosses the most of it. Then it subtracts the thread's weight along that line and asks again.

Lines must be straight and must end on pegs, so the thread cannot simply trace an outline. It crosses the whole frame, every time, and the picture emerges from where the crossings pile up: dense in the shadows, sparse in the light. That is also why a circle works so well. Every chord of a circle passes through the middle, where the subject usually is.

Thousands of chords, none of them drawn where the picture is; all of them drawn through it.

The search knows when to stop. A line whose average remaining darkness is less than half the thread's weight would make the frame worse, not better, so once no such line is left the frame is finished. Bright frames use fewer lines, dark ones more, and the slider for lines is only a ceiling. Opacity and thickness set how heavy each pass of thread is, and so how many passes a frame needs.

A video is nothing but many frames, so each one is solved on its own, spread across every core of your machine in Web Workers. The lines between pegs are rasterised once and shared by all frames of a clip, which leaves each step with nothing to do but sum a few hundred short lists of pixels. Frames come out as geometry, not pixels: a list of peg numbers per thread. They are drawn again at any size for playback, for a PNG or SVG, or for the video file, which is encoded right in the browser with WebCodecs.

III.

Reference

For the command line and for your own code.

Installation

Threadreel needs Node 18 or newer, and ffmpeg on the PATH for video files. Pictures need nothing else.

git clone https://github.com/sankshitpandoh/threadreel
cd threadreel && npm install && npm link

threadreel -i clip.mp4 -o clip-threads.mp4
threadreel -i photo.jpg -o photo.svg

A still that draws itself

Give a picture and ask for a video: the thread is laid down one line at a time over six seconds, then held.

threadreel -i photo.jpg -o photo.mp4 -intro 8 -hold 3

As a library

import { Threader, rasterize, toSVG } from 'threadreel';

const threader = new Threader({ shape: 'circle', pegs: 240 });
const result = threader.solve(imageData); // { width, height, data }
const png = rasterize(result, { width: 1080 });
const svg = toSVG(result, { width: 1080 });
-i path
A picture (PNG, JPEG) or any video ffmpeg can read.
-o path
Where to write it: .mp4 .webm .gif for video, .png .jpg .svg for one frame, .txt for stringing instructions, %04d.png for every frame. Repeatable.
-shape s
circle (square crop), ellipse or rectangle. Default circle.
-p n
Pegs around the frame. Default 240.
-n n
Most lines per frame; the search usually stops earlier by itself. Default 2500.
-mode m
mono for one thread, color for cyan, magenta and yellow (or red, green and blue on black).
-bg b
white with a dark thread, or black with a light one.
-opacity x
How much one pass of thread covers, 0 to 1. Default 0.3.
-thickness x
Thread width in thousandths of the frame. Default 1.
-q px
Working resolution for the search. Default 128.
-s px
Output size, longer side. Default 1080.
-fps n
Frames per second to take from the video. Default 12.
-t sec
Use only the first sec seconds.
-intro, -hold sec
Draw the first frame in, hold the last. Defaults 0 for video, 6 and 2 for a still.
-pegs-visible
Draw the pegs in red.
-j n
Worker threads. Defaults to every core.
-seed n
Fix the random tie-breaks to repeat a result exactly.
-v
Report progress.
